# MyTab

Track who owes you, what you owe, and what you sell. Built for shops and anyone who sells on credit.

- `index.html`: landing page (mytab.com.ng)
- `app/`: the app (single-file, works offline, syncs between phones automatically)
- Backend: https://github.com/Damola1-tech/mytab-backend (Express + Postgres on Render)

Tabs: Owe me, Sales, I owe, Summary. Sales charts are a Pro feature.

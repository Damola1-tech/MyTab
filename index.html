How it works

No training needed. If you can send a WhatsApp message, you already know how to use MyTab.

1

Add a customer

When someone buys on credit, add their name and number in a few seconds. Their phone number stays private, only you can see it.

2

Record what they owe

Tap a common amount or type it in. MyTab keeps a running balance for every customer, so you're never guessing.

3

Get paid

Send a WhatsApp reminder with one tap. When they pay, mark it settled, full or part payment, both work.

Made for how you actually run your shop
